🗑 Account aur Data Delete

Aap apna EduSpark account aur data kabhi bhi delete kar sakte hain। Ye page batata hai kaise।

Aakhri update: 13 October 2026

App ke andar se (sabse tez)

1. EduSpark kholo aur upar apni profile photo par tap karo
2. Profile page par neeche jao aur "🗑 Account और data delete करें" dabao
3. Confirm karo aur DELETE likho
4. Agar Google se sign in tha, to suraksha ke liye Google se ek baar dobara sign in karna padega
Delete hote hi data turant hata diya jata hai aur app naye sire se shuru ho jata hai।

Kya delete hota hai

• Aapka profile: naam, username, photo, board
• Aapka email aur Google user ID ka record
• Notification token
• Aapke bheje saare doubts (aur unke jawab)
• Aapka Firebase login account

Kya delete nahi hota

Agar aapne optional analytics/crash reports allow kiye the, to unka anonymous data Google (Firebase Analytics), Microsoft (Clarity) aur Sentry ke paas unke apne niyamon ke hisaab se rehta hai। Hum use aapke naam ya email se nahi jodte।
